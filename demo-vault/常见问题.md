# 常见问题

## 没有显卡能用吗

能。embedding 和重排模型都可以在纯 CPU 上跑，第一次会慢一些，之后正常使用。看图找书这类需要页面级视觉模型的功能，没有显卡的话可以直接关掉，不影响文字搜索。

## 安装复杂吗

目标是下载安装包、双击安装、打开就能用，不需要用户自己装 Python、配置命令行环境。重型的可选组件（比如本机 OCR）会在你真正启用对应插件的时候才下载，不会让安装包本身变得特别大。

## 我的笔记会被上传到云端吗

不会。默认情况下笔记内容全部在本机处理，向量库、词法索引都存在本地磁盘上。只有你自己主动开启云端 OCR 之类的可选功能时，对应的那部分内容才会发给对应的云端服务。

## 可以只用命令行 / MCP，不开图形界面吗

可以。GUI 只是众多插件之一，不启用它完全不影响 MCP 工具或命令行的使用——这也是插件化架构要验证的一条：任何一个非必需插件被关掉，核心功能都不受影响。
